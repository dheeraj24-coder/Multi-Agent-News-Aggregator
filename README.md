Multi-Agent News Aggregator using Google ADK
🚀 Overview

This project is a Multi-Agent AI News Aggregator built using Google Agent Development Kit (ADK) and Groq Llama 3.3 70B.

The system uses a ParallelAgent architecture where multiple AI agents work simultaneously to collect and generate news updates from different domains.

Agents Included

🏏 Cricket News Agent

Provides cricket news and match updates.
Covers tournaments, player performances, and major cricket events.

🌦️ Weather News Agent

Provides weather forecasts and climate updates.
Delivers concise weather-related information.

📈 Stock Market News Agent

Provides stock market trends and financial updates.
Covers market movements and investment-related news.

All three agents run in parallel, reducing response time and improving efficiency.
